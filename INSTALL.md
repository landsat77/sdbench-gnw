# SD Bench — installation

Requires Retro-Go SD **v2.0.0-rc1 or later** on the Game & Watch.

1. Copy `homebrews/SDBench.bin` from the zip to the `/homebrews/` folder of
   the SD card.
2. Start "SD Bench" from the Homebrew tab, press A. The card needs 33 MB of
   free space; the test files are deleted at the end.

A = start, B = cancel / back, PAUSE/SET = Retro-Go menu. The results are
added to `/sdbench.txt` on the card.

# SD Bench — installation (français)
